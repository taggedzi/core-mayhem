## Original synthesized effects: MIT

All active game sound effects are synthesized from oscillators, deterministic
noise, envelopes, filters, and echoes. No third-party recordings, samples,
or reference audio are used by the generators. The generator code and
resulting audio files are covered by the root MIT license.

The 14 combat files under `core-mayhem/src/audio/generated/` are:

- `activate-buff.wav`
- `activate-debuff.wav`
- `core-death.wav`
- `core-repair.wav`
- `core-shield-down.wav`
- `core-shield-up.wav`
- `fire-cannon.wav`
- `fire-laser.wav`
- `fire-missile.wav`
- `fire-mortar.wav`
- `impact-armor.wav`
- `impact-core.wav`
- `impact-miss.wav`
- `impact-shield.wav`

Regenerate them with `npm run audio:generate` from `core-mayhem/`.
The source is `core-mayhem/scripts/generate-sfx.mjs`. Files are mono,
44.1 kHz, 16-bit PCM WAV, with fixed seeds for reproducible output.

The separate `core-mayhem/src/audio/generated-low-health-alarm.wav`
is generated by `core-mayhem/scripts/generate-alarm.mjs` and is also MIT
licensed. It uses mono, 22.05 kHz, 16-bit PCM WAV.

These effects were developed with Codex assistance. Preserve the MIT license
when redistributing them.

## Synthesized announcer: MIT

The 49 WAV recordings under `core-mayhem/src/audio/announcer/` are original
announcement scripts rendered offline with eSpeak NG 1.52.0's built-in
`en-us+m3` formant voice. The scripts, generator, and resulting recordings
are made available under the root MIT license. No sampled voice packs,
MBROLA voices, cloned voices, or third-party speech recordings are used.

The editable scripts and pool mappings are in
`core-mayhem/scripts/announcer-lines.json`. Generate with
`npm run audio:announcer`; eSpeak NG must be installed on the development
machine. Set `ESPEAK_NG_PATH` to its executable if it is not on PATH.
`core-mayhem/scripts/generate-announcer.mjs` records engine settings and
clip durations in `src/audio/announcer/manifest.json`.

The game distributes only generated WAVs and metadata, not the eSpeak NG
engine, voice databases, or program code. eSpeak NG itself is separately
licensed GPL-3.0-or-later: https://github.com/espeak-ng/espeak-ng . Using a
GPL program does not by itself place its output under GPL; see
https://www.gnu.org/licenses/gpl-faq.html#GPLOutput .

The audio settings disclose that the announcer is synthesized. Players need
no speech service, API key, or local synthesizer to hear these bundled clips.
